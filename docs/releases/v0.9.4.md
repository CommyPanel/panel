# CommyPanel 0.9.4

Small fixes and improvements on top of 0.9.3.

## What's new

- **Environment variables, one at a time.** The dialog with every variable is gone. Each variable has a **pen**: it asks for your password (nothing if you confirmed it recently), shows only that variable's value and lets you change it. **Download as .env file** saves every variable of the app as `.env.<app name>` (for example `.env.dotnet`) so two apps' files cannot be mixed up. It needs a recent password and is recorded in the audit log as **dangerous**, because the file holds secrets. **Delete all** is unchanged.
- **Ending a watch.** The confirmation dialog for **End the watch now** closed only on a second click, which then said the watch was already over. The dialog now closes at once. The same fix applies to the dialogs for going live again and for promoting or stopping a gradual rollout.
- **Dialog buttons.** The buttons of the dialog that asks about a domain you typed but did not add could spill out of it on a narrow screen. Dialog buttons now wrap.

## Before you upgrade

- No new columns, no new permissions and no new ports. Run `sudo commypanel upgrade`.
- Opening a value (`app.env_revealed`), changing one (`app.env_changed`) and deleting all (`app.env_cleared`) are audited as warnings, downloading the file (`app.env_downloaded`) as danger.

## Known limitations

- A value with a line break is written to the `.env` file inside double quotes with `\n`, as other tools do. CommyPanel's own **Import** reads one value per line and does not turn `\n` back into a line break.
- Everything else in 0.9.3 is unchanged.

## Requirements

Unchanged: Ubuntu 24.04 or 26.04, or Debian 13 or newer, with systemd; `amd64` or `arm64`; root access; at least 1 GB of RAM.

```bash
# Install
curl -fsSL https://github.com/commypanel/panel/releases/latest/download/install.sh | sudo bash

# Upgrade
sudo commypanel upgrade
```
