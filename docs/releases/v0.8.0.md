# CommyPanel 0.8.0

CommyPanel now speaks **English, French, German, Spanish, Russian, Ukrainian and Turkish**. Every person chooses their own language, and anyone can improve a translation or add a language by editing one file.

CommyPanel is still pre-1.0.

## What's new

### The panel in your language

- **All seven languages are installed with the panel.** The first-run setup page has a language box (it starts with your browser's language when it is offered, otherwise English), and that becomes the first admin's language.
- **A language for every person.** When you add a user you choose their language, and it starts as your own. Everyone changes theirs under **Settings → Appearance**, and it affects only their own account. The login page uses the browser's language, with a box to change it for that visit.
- **About 1,570 sentences** of the interface are translated, together with the permission names and explanations, the status names, flash messages and Laravel's own messages (form errors, sign-in, pagination). Dates, numbers and durations follow the language too.
- **English is the fallback.** A sentence that is not translated shows in English, so a partly translated language still works.
- **Translations are drafted, not yet reviewed.** All six were drafted with a tool and need a native speaker's review: see `lang/README.md`. Corrections are welcome as pull requests.

### Adding or improving a language

- One file per language, `lang/<code>.json`, with the English sentence as the key. Add a language with one line in `config/commypanel.php` and one new file. `npm run i18n:check` verifies placeholders, tags and plural forms, and it runs in CI. See _Translating the panel_ in `CONTRIBUTING.md`.

## What is not translated

- The command line, the agent, the documentation and the audit-log action codes (such as `database.remote_opened`) stay in English.
- **Text saved by background work stays in English**, whichever language the person uses: a deployment's error and build log, rollout and watch notes, certificate and provisioning errors, deployment messages sent to a chat, and API answers.
- Messages that come from the agent or from Docker ("Agent error: …") stay in English.

## Before you upgrade

- The upgrade adds a `locale` column to `users`. Existing users keep English until they choose another language.
- No new ports, files for the agent or permissions.

## Requirements

Unchanged: Ubuntu 24.04 or 26.04, or Debian 13 or newer, with systemd; `amd64` or `arm64`; root access; at least 1 GB of RAM.

```bash
# Install
curl -fsSL https://github.com/commypanel/panel/releases/latest/download/install.sh | sudo bash

# Upgrade
sudo commypanel upgrade
```
