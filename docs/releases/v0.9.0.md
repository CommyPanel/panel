# CommyPanel 0.9.0

This release adds **ready-made apps** (Meilisearch, Typesense, Grafana, Elasticsearch and Kibana), shows you your **encryption key** so you can keep a copy, adds **active sessions** you can review and end, an **audit log export**, and **signed releases**. Please read **Before you upgrade**.

CommyPanel is still pre-1.0.

## What's new

### Ready-made apps

- **Apps → New app → A ready-made app** installs **Meilisearch**, **Typesense**, **Grafana**, **Elasticsearch** or **Kibana** from their official images, at a version CommyPanel pins. They get releases, rollbacks, logs, volumes, domains and HTTPS like any other app.
- Passwords and keys are **generated** and stored encrypted. The new permission `apps.credentials` lets someone press **Show access details** on the app's page, which asks for their password and is audited.
- **Elasticsearch** runs as one node with security on and needs about 2 GB of memory. It starts without the host setting `vm.max_map_count`, but is faster with it; the create page and `docs/quick-install.md` say how to set it.
- **Kibana** is wired to an Elasticsearch app you choose: the two are linked over a private network and Kibana gets its own `kibana_system` user.

### Your encryption key

- The last step of the first-run setup shows the panel's **encryption key** (`APP_KEY`) as a password field with **Show** and **Copy** buttons, and asks you to save it: backups never hold it, and without it a restored panel cannot read its stored secrets.
- It is also under **Settings → Encryption key**, with its own permission `server.key`, a password confirmation, and an audit entry on every visit graded **high risk** (red).

### Sessions

- **Settings → Security → Active sessions** lists every browser you are signed in with (browser, system, IP address, last active), and lets you sign one out or all the others.
- With `sessions.view`, the **Sessions** button on the Users page shows where someone else is signed in. With `sessions.revoke` you can also sign them out. You cannot do it to users with more access than you, and nobody can to the super user. Both are audited.

### Audit log export

- With `audit.export`, **Export CSV** and **Export JSON** on the audit log download the entries that match your filters (up to 50,000). It asks for your password and is itself audited.

### Signed releases

- Each release is signed with an **Ed25519** key. The installer checks the signature before it unpacks anything. An upgrade is checked with the key of the version you already run, and a first install with the key built into the installer, whose fingerprint is in the docs.
- An unsigned release is refused unless you pass `--allow-unsigned`. `docs/installing.md` shows how to check a release by hand.

## Before you upgrade

- **The upgrade adds columns** (a template and a health timeout per app). Run `sudo commypanel upgrade`.
- **New permissions:** `apps.credentials`, `server.key`, `sessions.view`, `sessions.revoke` and `audit.export`. The built-in admin role and the super user have them; **roles you made yourself do not** until you grant them.
- **This upgrade is not signature-checked**, because the version you run does not check signatures yet. Releases after it are.
- **No new ports.** Sessions need the default database session driver.

## Security notes

- The encryption key is shown only after a password confirmation and the permission, and every visit is recorded as high risk. Anyone who sees it together with a copy of the database can read every stored secret.
- Session ids never leave the server: pages get a keyed hash, and a sign-out only matches sessions of that one user.
- Ready-made apps run through the same agent limits as your own: the agent still accepts only `commypanel/` images. The official images appear only as the first line of the build.
- The audit export neutralises cells that start with `=`, `+`, `-` or `@`.

## Known limitations

- Kibana's first deploy fails if its Elasticsearch app is not running.
- If you change a password inside Grafana or Elasticsearch, **Show access details** still shows the original.
- The new translations are unreviewed drafts.

## Requirements

Unchanged: Ubuntu 24.04 or 26.04, or Debian 13 or newer, with systemd; `amd64` or `arm64`; root access; at least 1 GB of RAM (2 GB more for Elasticsearch).

```bash
# Install
curl -fsSL https://github.com/commypanel/panel/releases/latest/download/install.sh | sudo bash

# Upgrade
sudo commypanel upgrade
```
