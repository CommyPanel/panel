# CommyPanel 0.2.1

A patch release for 0.2.0. It keeps PHP up to date on the server, and fixes a 502 error when reloading an app page.

## Fixes

- **PHP security updates.** PHP had two serious flaws (CVE-2026-109618 and CVE-2026-109619, together called PHP2Shell) that let anyone run code through PHP-FPM. The installer now upgrades PHP to the newest build your distribution offers, and checks that the installed build has the fix. A fresh install stops with a clear message if it does not; an upgrade shows a warning with the command to run (`sudo apt-get update && sudo apt-get upgrade`). Set `COMMYPANEL_ALLOW_VULNERABLE_PHP=1` to install anyway, at your own risk.
- **PHP pool hardening.** The panel's PHP pool turns off the two features the flaws go through (session upload progress and, on PHP 8.5, fatal error backtraces). The panel uses neither.
- **502 when reloading an app page.** Reloading an app's detail page (Cmd/Ctrl+R) could show "502 Bad Gateway" while clicking through to it worked. The response headers were larger than nginx's default buffer. The panel no longer sends the preload headers, and its nginx site now has a larger buffer.

## Before you upgrade

- Run `sudo commypanel upgrade`. If the installer warns that PHP is out of date, run `sudo apt-get update && sudo apt-get upgrade` and then `sudo systemctl restart php*-fpm`.
- Panel domain sites that were already written keep the old nginx buffer until their next change. The headers fix makes this unnecessary.

## Requirements

Unchanged: Ubuntu 24.04 or 26.04, or Debian 13 or newer, with systemd; `amd64` or `arm64`; root access; at least 1 GB of RAM.
