# CommyPanel 0.4.1

A fix for new installs on **Debian 13**.

## Fixed

- **A blank page on the setup link (and on every page at `https://<address>:8443`) on Debian 13.** Debian's nginx 1.26 package passes the host name to PHP without its port, so the panel asked for its scripts and styles on port 443, where nothing listens before a panel domain exists. The panel's nginx site now passes the host exactly as the browser sent it. Ubuntu was not affected.

## Upgrading

- `sudo commypanel upgrade` rewrites the panel's nginx site, which fixes an install that already shows the blank page. If you cannot get to the panel to run it, upgrade from the server's command line as usual; no data changes.

```bash
sudo commypanel upgrade
```
