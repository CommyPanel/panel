# CommyPanel 0.9.1

A small release.

## What's new

- **Search engines are told to ignore the panel.** Every page, the sign-in page and the error pages included, now carries `<meta name="robots" content="noindex, nofollow">`, so crawlers do not index it or follow its links. This is built into the page template and needs no setting.

## Before you upgrade

Nothing: no new columns, ports or permissions. Run `sudo commypanel upgrade`.

## Known limitations

- `robots.txt` is unchanged (it allows crawling) on purpose: a crawler that is not allowed to fetch a page cannot see its `noindex` instruction.

## Requirements

Unchanged: Ubuntu 24.04 or 26.04, or Debian 13 or newer, with systemd; `amd64` or `arm64`; root access; at least 1 GB of RAM.

```bash
# Install
curl -fsSL https://github.com/commypanel/panel/releases/latest/download/install.sh | sudo bash

# Upgrade
sudo commypanel upgrade
```
