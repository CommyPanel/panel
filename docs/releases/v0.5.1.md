# CommyPanel 0.5.1

CommyPanel now finds the server's public IP address by itself, and shows it wherever DNS records are needed.

## What's new

- **The server's address is detected automatically.** There is no "Detect" button to press any more. The first time a page needs the address (the first-run page, Domains, an app's Domains tab, a domain's page, the app wizard's domain step), CommyPanel finds it in the background and shows "Finding this server's public address…" until it is done.
- **It reads the server's own network connection first**, so on most servers (Hetzner, DigitalOcean, bare metal) nothing leaves the machine. Only a server with no public address on its interface (behind a NAT, as on some clouds) is looked up through `api.ipify.org`, once. `COMMYPANEL_ADDRESS_LOOKUP=false` switches that off.
- **If it cannot be found, you are asked.** The page says so and shows the two fields; it does not try again for ten minutes.
- **A "Wrong IPs detected?" button** is next to the address everywhere it is shown. It opens the two fields (IPv4 and optional IPv6) with a **Detect again** button. An address you entered is never replaced by a detection, and every change is recorded in the audit log with what it replaced.

## Before you upgrade

- `sudo commypanel upgrade` as usual. An address you saved before stays as it was, marked as entered by you; use **Detect again** if you want it looked up anew.
- The agent has a new read-only call (`/v1/system/addresses`) that lists the public addresses on the server's interfaces. Nothing is sent over the network to find them.
- The panel makes one more outbound call by itself, to `api.ipify.org`, only on a server that has no public address of its own, and not at all with `COMMYPANEL_ADDRESS_LOOKUP=false`.

## Also in this release

- The install check on GitHub (Debian 13, Ubuntu 24.04 and 26.04) installs the PHP dependencies before building, which it did not before and which made it fail. It changes nothing in the product.

## Known limitations

- A server with several public IPv4 addresses and no clear default route gets the first one; correct it with **Wrong IPs detected?** if it is not the one your domains should use.
- A server behind a NAT with the outside lookup switched off has to be given its address by hand.

## Requirements

Unchanged: Ubuntu 24.04 or 26.04, or Debian 13 or newer, with systemd; `amd64` or `arm64`; root access; at least 1 GB of RAM.

```bash
# Install
curl -fsSL https://github.com/emrecanful/commypanel/releases/latest/download/install.sh | sudo bash

# Upgrade
sudo commypanel upgrade
```
